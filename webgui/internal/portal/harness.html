mayhem-b200 panels harness

dev-only — driven entirely by internal/portal/testdata fixtures — see PANELS.md

Perturbs the loaded fixture on a timer and calls render() again, to exercise the diffing/highlight-fade/waterfall-scroll/autoscroll paths a single static render can't show.

The adsb, map and geotable panels draw an OpenStreetMap basemap, pulling live tiles through this server's /api/tiles/{z}/{x}/{y}.png route — the same one the real portal serves. With no network they fall back to their own graticule, exactly as they do in production; run this harness with -tiles off to see that fallback on a machine that does have one.
